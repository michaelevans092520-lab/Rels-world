# Unique builds (plan, not built yet)

Goal: no two players feel the same, even at the same level.

1. **No locked classes.** Every combat style is a skill anyone can level, OSRS-style: Sword, Bow, Strength, Fire, Water, Earth, Air/Star, Necromancy.
2. **Limited loadout.** Each style unlocks abilities as it levels (fireball, multishot, raise skeleton...). Only ~4 ability slots can be equipped at once, which forces choices.
3. **Perk trees per style.** Level-ups give perk points (e.g., Fire: burn damage vs explosion size; Bow: crits vs poison).
4. **Cross-style combos.** Mixing styles unlocks hidden effects: water + fire = steam (blind), necromancy + fire = burning skeletons, strength + earth = ground-slam knockback.
5. **Gear with bonus stats.** Drops roll extras (+fire damage, lifesteal, faster draw) so players hunt gear for their build.
6. **Cheap respec** (coins) so experimenting is encouraged.
7. **Combat triangle** like OSRS: melee > ranged > magic > melee.
8. Online later: builds create team roles (tank, water-healer, necro army).

Each region teaches its style through a trainer quest (see `map-design.md`).
