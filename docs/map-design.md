# Map design notes

## Current plan: Pangea first
- Start with **one connected supercontinent**. Every region from the original game is joined and walkable, with no boats or loading screens needed to get between them.
- Regions (from the original 8 islands): Ember Key, Mossreach, Saltglass, Duskfen, Frostmere, Cinder Isle, Coral Drift, Starfall.
- Each region keeps its own look (ground, trees, weather), monsters, and boss, so it still *feels* like a separate land.
- Borders between regions are natural transitions (forest edge, river crossing, mountain pass, beach), so they're easy to cut apart later.

## Later (maybe): break Pangea apart
- Possibly split the continent into separate islands down the line (story event? "the Shattering"?).
- To keep that easy, build each region as its own chunk of the map with clear borders and a few chokepoints (bridges/passes) that could become docks/boat routes.

## Open questions

- Level ranges per region.
